## 🐛 COMMON DEMO ISSUES

### **Camera Permission:**
- Browser will ask for camera access
- Click "Allow"
- Use Chrome/Edge for best results

### **Offline Mode:**
- Use DevTools (F12) → Network → Offline
- Or turn off WiFi manually
- Must turn back online to submit

### **Ports in Use:**
- Backend: Port 8000
- Frontend: Port 3000
- Make sure they're not blocked
